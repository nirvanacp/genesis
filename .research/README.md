# Technical research

Start with [Genesis live website customization](live-dom-customization/README.md), the revised document set from 27 October 2026. It follows the clarified requirement to customize the original website incrementally, with a Rust runtime and JS/TS creator code. It covers research, architecture, creator API examples, authoring/reliability, LIVE-01 through LIVE-07 milestones and an evidence register. All runtime qualification is pending.

The documents below preserve earlier alternatives and reasoning. Their default presentation and creator-language recommendations are superseded where they conflict with the new set.

- [Browser runtime and website UI layer framework, 27 October 2026](applet-framework/2026-10-27-browser-runtime-and-ui-layer-framework.md). Earlier proposal covering view limits, bookmarks, Wasm, JNI and browser hosting. Its persistent-data distinction remains useful; its separate-result default and Rust-only creator assumption have been revised.
- [Architecture review and build roadmap, 27 October 2026](architecture-review/2026-10-27-architecture-and-build-roadmap.md). Earlier review of eight Genesis research documents against the Bonsai reference and platform documentation. Contains twelve findings and historical GEN-01 through GEN-08 gates. The new LIVE roadmap replaces it for incremental website customization.
- [How Genesis turns a website into a custom applet, 26 October 2026](rust-monorepo/2026-10-26-runtime-walkthrough.md). Standalone technical walkthrough of the YouTube example, execution contexts, snapshots and patches, adapter records, creator rendering and the action return path. Includes illustrative messages, failure handling and code ownership.
- [Rust monorepo design, 26 October 2026](rust-monorepo/2026-10-26-codebase-design.md). Proposes ten first-party build units across native Android and browser Wasm, Rust applet UI, a thin Android embedding boundary and qualification gates. Includes a [direct dependency inventory](rust-monorepo/2026-10-26-dependencies.md) with version and license observations. Documentation only; no dependencies installed or runtime tested.
- [Creator framework architecture options, 26 October 2026](applet-framework/2026-10-26-architecture-options.md). Compares templates, schemas, an app language, typed React, remote UI, standalone web applets and source-page scripts. Recommends a shared source/action runtime with progressive authoring freedom, staged validation and recoverable activation.
- [Source DOM and React projection, 26 October 2026](source-dom-react/2026-10-26-research.md). Evaluates the dual-DOM proposal, Chromium changes and reusable open-source software. Includes a [proposed architecture](source-dom-react/2026-10-26-architecture.md) and [engineering roadmap](source-dom-react/2026-10-26-roadmap.md). No runtime implementation or benchmarks.
- [Customizable applets backed by browser tabs, 24 October 2026](customizable-browser-applets/2026-10-24-technical-analysis.md). Compares page modifications, live website views, native catalogs and programmable web interfaces. Includes required components, failure modes, formulas and a qualification plan. Research and proposals only, with no runtime benchmarks.
