# Match the post route before post pages

- Goal: Open a post in the applet's Post screen instead of the website sheet.
- Changes: `applet.json` lists the `post` route before the `post-pages` website route. A trailing `*` pattern also matches its bare prefix, so `/:handle/status/:id/*` had been taking every `/:handle/status/:id` URL. Spec routes and verification updated from the acceptance run.
- Decisions: None.
- Verification: `check` and `build` passed, and `matchRoute` resolves a bare status URL to `post`, a photo URL to `photo` and `/analytics` to `post-pages`. Installed as revision 7 on `emulator-5554` (Android 17) with a signed-in account and no running service: Post with replies, the one-photo media viewer and Back were checked. No X action was performed.
