# Rewrite on SDK 1.0

- Goal: Move the X applet to manifest schema 5 and SDK 1.0 with the same five sections, Saved row and Categories library, as part of the Genesis repository revamp.
- Changes: New typed adapters in `src/sources` (timelines, notifications, bookmarks, likes, posts, profiles, media, explore and search, account) with like, bookmark and reload intents. One React foreground in `src/app.tsx` with screens in `src/screens`, shared components and a rewritten theme. Category editing moves to `save` and `manage` screens. Routes follow X's `/i/history` bookmarks and likes paths. The backend and its records are unchanged. The old pages, view models and CSS files are removed.
- Decisions: [decision-0003](../.specs/decisions.md#decision-0003-rebuild-on-sdk-10-with-typed-sources-and-screens), [decision-0004](../.specs/decisions.md#decision-0004-edit-categories-on-screens).
- Verification: `check`, `typecheck` and `build` passed. The build was installed on `emulator-5554` (Android 17) with a signed-in account and no running service. Home, Explore, the own Profile and Saved Bookmarks were checked in light mode, and Categories showed its unavailable state. Like and bookmark writes, Categories data, post detail, the media viewer, Notifications, search, signed-out states and dark mode were not exercised. No X action was performed.
