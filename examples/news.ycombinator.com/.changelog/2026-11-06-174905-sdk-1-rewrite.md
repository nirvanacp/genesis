# Rewrite on SDK 1.0

- Goal: Move the Hacker News applet to manifest schema 5 and SDK 1.0 with the same tabs, screens and saved data, as part of the Genesis repository revamp.
- Changes: New typed adapters in `src/sources` (feeds, items, profiles, information pages, account, submit form) with vote, submit, reload and sign-out intents. One React foreground in `src/app.tsx` with screens in `src/screens`, shared components and a rewritten theme. The library storage now runs through the `bookmarks` service with unchanged record shapes. The old pages, view models and CSS files are removed.
- Decisions: [decision-0003](../.specs/decisions.md#decision-0003-rebuild-on-sdk-10-with-typed-sources-and-screens), [decision-0004](../.specs/decisions.md#decision-0004-edit-saved-stories-on-a-screen).
- Verification: `check`, `typecheck`, `build` and the debug APK build passed. Revision 4 was installed on `emulator-5554` (Android 17) with a signed-in account and the existing local service. Home, a discussion, Me and Saved were checked in light mode, and Home in dark mode. Voting, posting, sign-out, Save writes, category edits, signed-out states and information pages were not exercised. No HN action was performed.
