# Make an app work your way

Genesis lets you build custom apps over the websites you already use. Describe what you want to a coding agent, try the result on Android, and keep improving it.

Make a site easier to read. Add a private collection. Bring several websites into one app with a shared Saved screen.

Your custom app runs inside Genesis. We call it an **applet**.

## Start here

Already have an app installed? Start with [Use your apps](use/everyday-use.md). You can use an existing app without setting up a coding agent.

Want to build or change an app? Follow this path. Each page gives you one next step.

## Current availability

Genesis currently has an Android development workflow. Creators need a compatible debug build and SDK/tools archives supplied by a Genesis maintainer. These packages are not yet on the public npm registry.

A public app store, production app distribution, and built-in coding-agent connectors are future work. The guides explain what you can do with the current tools.

## For your coding agent

These pages explain the product and the decisions you make. The [creator kit](../factory/README.md) contains the implementation instructions, SDK reference, and verification guides your agent needs.

You do not need Genesis's Android or Rust source to build an applet.
