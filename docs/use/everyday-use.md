# Use your apps

[Learning path](../README.md) · Use an installed app

Open Genesis and choose an app from **Apps**. Each app decides its own screens and custom features.

## Move around

Use the app's sections to switch between its main screens. A section may show a live website or a custom page such as Saved.

- Use Android Back to leave a detail screen or dismiss a supported dialog.
- An external link may open a reader. **Close reader** returns to the app that opened it.
- Open **Applet options** and choose **Return to Genesis** to pick another app.

Section switches can restore your previous screen. Save important work before reloading, updating, or closing Genesis. A retained screen is not a guarantee that an unsaved draft will survive a restart.

## Sign in where you normally would

Use the website's sign-in screen inside the app. The website still controls your account and any verification challenge.

A custom feature may use separate app data. Signing into a website does not automatically connect a custom Saved library.

Read [Accounts, permissions, and privacy](accounts-and-privacy.md) before adding unfamiliar custom code or a service.

## If a page fails

Open **Applet options → Recovery → Open ordinary site** to try the website without the active customization.

You may also see **View original page** on a customization error. A website connection error has separate **Retry page**, **Back**, and **Open in browser** controls.

Opening the ordinary site does not repair a broken custom feature or an unavailable server. It can help you continue browsing.

## If text or video looks broken

Try **Applet options → Rendering → Hardware acceleration** if that option is available in your build. The setting applies to this applet on this device.

This has corrected rendering defects in the X development app. It is not a general fix for website failures. See [Troubleshooting](../maintain/troubleshooting.md).
