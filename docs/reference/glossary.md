# Glossary

[Learning path](../README.md) · Reference

| Term | Plain meaning |
| --- | --- |
| adb | Android's tool for connecting a computer to a device or emulator |
| Adapter | App code that reads and changes a supported website page |
| APK | An Android installation file, such as the Genesis host app |
| Applet | A custom app running inside Genesis |
| Applet ID | The stable name used to identify an app's package, local records, and service connections |
| App page | A screen the app owns rather than a live website page |
| Backend | A server outside the phone that stores data or handles app rules |
| Build | Turn an app's source files into an installable bundle |
| Capability | A declared Genesis function the app needs, such as storage or services |
| Coding agent | An AI coding tool that reads instructions, edits files, and runs checks |
| Creator kit | The matching guides and agent instructions copied into an app's factory folder |
| Debug host | A Genesis development build that accepts supported adb applet installation |
| Host | Genesis itself, which runs applets and websites |
| Manifest | The applet.json file declaring identity, sources, pages, and capabilities |
| Origin | A website's scheme and host, plus a port if present, such as https://example.com |
| Reader | A browser view for a linked page, with a control to return to its opener |
| Revision | The identifier for a particular built version of app code |
| Rollback | Select previous compatible code; it does not restore older data |
| Route | A website path or screen your app handles |
| SDK | The public code tools your app uses to work with Genesis |
| Service connection | Configuration that lets an app talk to its declared backend |
| Source | A live website document used by an app |
