# Applet work

Follow [factory instructions](../AGENTS.md), [rules](../guides/rules.md) and root repository instructions. Read the selected applet's `.specs/current.md`, relevant decisions and README. Initialize missing records on first active customization under [record rules](../guides/applet-records.md). Use only flat `.specs` and `.changelog`; root phase storage applies to platform/shared work.

Preserve stable app identities, neighboring applets and data. Update route/model/renderer and interaction mappings together. Use [isolated rendering](../guides/isolated-applets.md), [navigation](../guides/navigation.md) and [interactions](../guides/interactions.md). Hidden source stays hidden; explicit website workflows preserve sessions and Return. Apply the shell/menu default unless overridden. Recognize clear shared intent under factory rules without promoting ordinary local preferences.
