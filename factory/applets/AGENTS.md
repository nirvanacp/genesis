# Applet work

Follow [factory instructions](../AGENTS.md), its [product-scope workflow](../guides/product-scope.md), and root repository rules. These applets use the public Genesis SDK. Read the current manifest, package selection, applet README and active plan for implementation status; historical prototype labels do not restrict the latest requested scope.

Each requested application keeps one stable applet identity. Its source sections, owned pages, services and verification fixtures are not separate everyday apps. Preserve working sibling applets and their data. Ask about unresolved material product choices before splitting an application or dropping required flows. Verify the complete requested journey, not only its newest feature.
