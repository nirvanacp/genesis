# X pull-to-refresh

- Goal: Restore expected refresh interaction on owned X screens and the private Categories list without keeping old cached rows ahead of fresh content.
- Changes: Added a reusable top-edge vertical pull gesture with release threshold, cancellation, visible status and duplicate-request protection. Browsing and Categories also have labeled refresh controls. Source refresh clears the current URL's merged window, opens that exact source/URL and waits for a replacement epoch's result. It times out visibly and never submits social actions. Categories refresh rereads its existing authoritative service. Incoming models must match the destination route kind.
- Decisions: The user explicitly requested missing pull-to-refresh and broken interactions. The agent uses existing SDK source navigation, preserves search/filter URLs and excludes inputs, horizontal tabs, nested scrollers, media and modal gestures. A gesture cannot accidentally click a post underneath. No backend migration or new platform API is required.
