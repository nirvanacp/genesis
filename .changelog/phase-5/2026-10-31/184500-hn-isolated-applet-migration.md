# HN isolated foreground migration

- Goal: Migrate the complete existing HN applet to hidden source extraction and a separate owned foreground while preserving its identity, backend and saved records.
- Changes: Schema-2 route inventory maps feeds, discussions, profiles and information to bounded validated models and owned renderers. Forms/account actions and articles use the explicit website provider. Existing Saved/Search modules receive scoped screen lifetimes, including section re-entry. Save/edit dialogs have a scrollable body, visible action footer and labeled category fields. SDK dependency is 0.4.0.
- Decisions: The user required both applets and the new framework; the agent preserved all existing service/data keys and the documented Search placeholder. Source cookies, form fields and logout tokens are not published. Unknown/loading/error states remain owned.
- Verification: HN CLI check, TypeScript and API-3 build passed. Separate emulator QA passed live feed/discussion/collapse, exact-source form presentation/Close, save/read-back, category creation/membership/filtering, keyboard entry and Saved re-entry. Disposable story/category were removed; baseline one story and two categories remained. Source accessibility isolation was checked after load. Everyday-host integration and broader failure qualification remain subsequent migration steps. No test files changed.
