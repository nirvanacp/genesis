# Native applet isolation container

- Goal: Implement and qualify the native pixel/input boundary before connecting isolated applet documents to the host.
- Changes: Added `AppletPresentation.java` with separate source, opaque backing, foreground and explicit website containers. It excludes hidden source accessibility/touch/focus, requires per-view audio muting, bounds source/reader ownership, supports source adoption/return and rejects stale foreground reveal callbacks. Failed foreground removal leaves the native backing in place. Host authority and lifecycle wiring remain separate pending work.
- Decisions: The agent qualified this prerequisite with a disposable QA APK rather than updating the everyday Genesis installation. Explicit phase controls replaced an unreliable timer-driven capture. Foreground readiness remains independent from source readiness; Close requests a fresh visual callback rather than revealing a pending document unconditionally. The user-requested full applet migration and interaction checks remain required.
- Verification: Android assemble/lint passed. On emulator WebView 156, synthetic foreground removal, provider adoption and Close preserved the expected pixel/accessibility boundary, and the mute API reported true. The QA package/device XML was removed. See the component report for limits. Real X/HN navigation, protected media, physical audio, TalkBack and host lifecycle/broker integration remain unverified and incomplete.
