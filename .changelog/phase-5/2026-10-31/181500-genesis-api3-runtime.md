- Goal: Connect schema-2 adapters to an independent owned foreground and expose ordinary websites through an explicit native provider.
- Changes: Added the API-3 Rust lifecycle reducer and Android executor, role/channel/document binding, route/session invalidation, bounded snapshots, foreground storage/services, native reader/adopted-session handling, modal/Back/leave guards, package compatibility and SDK registration/subscriptions. New packages retain stable applet data namespaces.

Public SDK/bootstrap and existing native service/storage workers are reused. One hidden source and one owned foreground run per active applet. Source sections reload on selection; bounded frontend history retains navigation identity. Full arbitrary website JavaScript restoration is not promised. User explicitly authorized framework changes and later factory instruction updates.
